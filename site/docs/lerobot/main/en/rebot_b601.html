reBot B601-DM

reBot B601-DM 是 Seeed Studio 为具身 AI 和模仿学习设计的开源、低成本机械臂。它带有follower arm（B601-DM，一个由 Damiao CAN 电机驱动的 6 自由度手臂加 gripper）和用于 teleoperation 它的leader arm（StarArm102 / reBot Arm 102，由 FashionStar UART 智能舵机驱动）。

本页涵盖单臂和双臂（双手）设置下的calibration和teleoperation。

左侧：处于零位的 B601-DM follower arm。右侧：处于零位的 reBot Arm 102 leader arm。图片由 Seeed Studio 提供。

安装 LeRobot 🤗

按照我们的安装指南操作，然后安装 reBot 支持：

pip install -e ".[rebot]"

这会引入 motorbridge（用于 B601-DM follower arm 的 CAN 电机控制）和 motorbridge-smart-servo（用于 reBot Arm 102 leader arm 的 FashionStar UART 舵机）。

已注册的设备类型

类型类别
rebot_b601_follower单臂 B601-DM follower arm 机器人
bi_rebot_b601_follower双臂（双手）follower arm 机器人
rebot_102_leader单臂 reBot Arm 102 leader arm teleoperator
bi_rebot_102_leader双臂（双手）leader arm teleoperator

双臂类型由两个单臂实例组成，并使用 left_ / right_ 前缀为每只手臂的 observation/action 键命名空间。每只手臂的设置通过嵌套的 left_arm_config.* / right_arm_config.* 参数传递。

查找 USB 端口

对于每个设备，使用以下命令查找与其电机总线关联的 USB 端口：

lerobot-find-port
在 Linux 上，卸载 `brltty`（`sudo apt remove brltty`），这样它就不会占用 leader arm 的 USB 串行端口。你可能还需要授予对串行 设备的访问权限：`sudo chmod 666 /dev/ttyACM* /dev/ttyUSB*`。

calibration

两只手臂都不会存储持久的硬件 calibration：每次连接时，电机都会根据手臂实际保持的位姿重新归零。calibration 只是记录该零位。当提示时，手动将手臂移动到其零位（如上所示的默认落坐位姿，gripper 完全闭合）并按 ENTER。

follower arm（B601-DM）

Single arm
Dual arm
lerobot-calibrate \
    --robot.type=rebot_b601_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=follower \
    --robot.can_adapter=damiao

leader arm（reBot Arm 102）

Single arm
Dual arm
lerobot-calibrate \
    --teleop.type=rebot_102_leader \
    --teleop.port=/dev/ttyUSB0 \
    --teleop.id=leader

teleoperation

两只手臂都 calibration 完成后，就可以用 leader arm 驱动 follower arm。follower arm 通过 Damiao 串行桥接器（can_adapter=damiao，默认）或 SocketCAN 适配器（can_adapter=socketcan）与其 CAN 总线通信。有关 SocketCAN 适配器配置的更多详细信息，请参阅 OpenArm 页面。

Single arm
Dual arm
lerobot-teleoperate \
    --robot.type=rebot_b601_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=follower \
    --robot.can_adapter=damiao \
    --teleop.type=rebot_102_leader \
    --teleop.port=/dev/ttyUSB0 \
    --teleop.id=leader
leader arm 和 follower arm 共享相同的关节名称（`shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_yaw, wrist_roll, gripper`），因此 leader arm action 可以直接映射到 follower arm 上。

如果某个关节的运动方向相反，请在 leader arm 的 joint_directions 中翻转其符号（gripper 还带有一个缩放系数，以将其范围扩展到 follower arm）：

lerobot-teleoperate \
    --robot.type=rebot_b601_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.can_adapter=damiao \
    --teleop.type=rebot_102_leader \
    --teleop.port=/dev/ttyUSB0 \
    --teleop.joint_directions='{"shoulder_pan":-1,"shoulder_lift":-1,"elbow_flex":1,"wrist_flex":1,"wrist_yaw":1,"wrist_roll":-1,"gripper":-6}'

录制 dataset

将 lerobot-teleoperate 换成 lerobot-record（使用相同的 --robot.* / --teleop.* 参数，再加上 --dataset.*）即可录制用于训练的 demonstration。完整的流程请参阅机器人的模仿学习。

有关硬件组装和接线，请参阅 Seeed Studio reBot wiki。
