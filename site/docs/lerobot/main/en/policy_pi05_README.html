π₀.₅（pi05）

本仓库包含 π₀.₅ 的 Hugging Face 移植版本，改编自 Physical Intelligence 的 OpenPI。 它被设计为一个具备开放世界泛化能力的视觉-语言-action 模型。

模型概览

特性π₀π₀.₅
时间条件通过 action_time_mlp_* 将时间与 action 拼接使用 time_mlp_* 进行 AdaRMS 条件化
AdaRMS不使用用于 action expert
分词器长度48 个 token200 个 token

参数量更高（包含 state 嵌入）更低（无 state 嵌入）

relative action

π₀.₅ 支持使用relative action进行训练，此时模型学习的是相对于当前机器人 state 的偏移量，而非绝对关节位置。这与 OpenPI 中的 relative action 变换（DeltaActions）一致，并且可以提升性能。

工作原理

  1. 在预处理期间，absolute action 被转换为相对偏移量： relative = action - state（针对选定的关节）。
  2. 使用根据相对分布计算出的统计量对 relative action 进行归一化。
  3. 在后处理期间，预测的 relative action 被转换回 absolute action： absolute = relative + state。

在 relative_exclude_joints 中列出的关节（例如 gripper）保持绝对。

配置

参数类型默认值说明
use_relative_actionsboolFalse启用 relative action 训练
relative_exclude_jointslist[str]["gripper"]保持绝对的关节名称（按子串匹配）
action_feature_nameslist[str]None运行时由 make_policy 从 dataset 元数据自动填充

训练示例

python -m lerobot.scripts.lerobot_train \
  --policy.type=pi05 \
  --dataset.repo_id=your_org/your_dataset \
  --policy.use_relative_actions=true \
  --policy.relative_exclude_joints='["gripper"]'

当 use_relative_actions=true 时，训练脚本会自动：

  • 从 dataset 计算 relative action 统计量（采样的 action chunk 级 relative action）
  • 用相对统计量替换标准 action 统计量以进行归一化
  • 在分布式训练中将这些统计量广播到所有进程

policy 权重的 EMA

OpenPI 在训练期间维护权重的指数移动平均（默认 ema_decay=0.99），并保留 EMA 副本用于 inference。要使用 LeRobot 训练器复现这一点，需启用 EMA 影子权重并设置恒定衰减：

python -m lerobot.scripts.lerobot_train \
  --policy.type=pi05 \
  --dataset.repo_id=your_org/your_dataset \
  --ema.enable=true \
  --ema.decay=0.99

此时 checkpoint 会在 pretrained_model_ema/ 中包含一份可直接加载的 EMA 权重副本，与实时权重并列。注意，影子权重是参数在 GPU 上的完整额外副本。与 OpenPI（在其 LoRA 配置中禁用 EMA）一样，EMA 不支持与 PEFT 适配器一起使用。
