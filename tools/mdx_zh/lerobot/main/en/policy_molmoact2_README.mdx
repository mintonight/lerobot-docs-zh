# MolmoAct2

该仓库包含 [MolmoAct2](https://allenai.org/blog/molmoact2) 的 LeRobot policy 实现，已移植到 LeRobot 中以实现训练、评估、checkpoint 保存和 dataset 兼容性。

该实现目前支持对标准 MolmoAct2 模型进行训练和评估。支持自适应深度 inference 的 MolmoAct2-Think 尚未包含在此 LeRobot policy 中，敬请期待。

如需论文中所报告实验使用的原始 MolmoAct2 训练代码，请参阅 [allenai/molmoact2](https://github.com/allenai/molmoact2)。

## LIBERO 评估

重要提示：我们发现 `num_steps_wait=10` 无法可靠地让 LIBERO 场景稳定下来，并可能降低测得的成功率。此 LeRobot 实现报告的所有 LIBERO 评估结果都使用 `num_steps_wait=50`。
