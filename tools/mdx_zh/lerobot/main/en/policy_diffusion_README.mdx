## 训练

参考实现会在训练期间维护 policy 权重的指数移动平均（EMA），并使用 EMA 权重进行评估。要复现这一行为，请启用训练器的 EMA 影子：

```bash
lerobot-train \
  --policy.type=diffusion \
  --ema.enable=true \
  ...
```

这样，checkpoint 中除了实时权重外，还会包含一份可直接加载的 EMA 权重副本，例如用于评估：

```bash
lerobot-eval --policy.path=outputs/train/.../checkpoints/last/pretrained_model_ema ...
```

EMA 衰减计划（`--ema.inv_gamma`、`--ema.power`……）默认采用参考实现的值。如果希望使用恒定衰减而不是预热计划（例如为匹配 openpi 的 pi0/pi05 训练），请设置 `--ema.decay=0.99`。
