# 第三方机器人与 teleoperator

LeRobot 生态远不止其官方支持的硬件。得益于 LeRobot 的插件架构，社区为各种机械臂和 teleoperator 构建了集成——从工业机械臂到经济实惠的爱好者平台、VR 头显、触觉设备以及完整的机械臂加 teleoperator 套件。本页展示了社区维护的集成，可用于 teleoperation、数据采集和 policy deployment。

> [!IMPORTANT]
> 这些项目由第三方开发和维护。有关安装说明、硬件要求和支持，请参阅各自的仓库。

即插即用插件通过包名自动发现：LeRobot 会导入任何已安装的、以 `lerobot_robot_` 或 `lerobot_teleoperator_` 为前缀的包。安装后，可直接在任何 LeRobot 命令中引用插件注册的 `type`（参见其 README——它可能与包名不同）：

```bash
pip install lerobot_robot_<name> lerobot_teleoperator_<name>

lerobot-record \
    --robot.type=<robot_name> \
    --teleop.type=<teleoperator_name> \
    --dataset.repo_id=${HF_USER}/my-dataset \
    --dataset.num_episodes=5
```

> [!TIP]
> ⚠️ 标记的是 LeRobot 的分叉/扩展项目。它们可能需要自定义设置，而非在未修改的安装上直接使用。所有其他条目均为即插即用插件。
