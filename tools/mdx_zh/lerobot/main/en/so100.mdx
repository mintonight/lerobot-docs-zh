# SO-100

在下面的步骤中，我们将说明如何组装 SO-100 机器人。

## 获取零件

请遵循此 [README](https://github.com/TheRobotStudio/SO-ARM100/blob/main/SO100.md)。它包含物料清单、零件采购链接以及 3D 打印零件的说明，并为首次打印或没有 3D 打印机的用户提供了建议。

## 安装 LeRobot 🤗

要安装 LeRobot，请遵循我们的 [安装指南](./installation)

除了这些说明之外，你还需要安装 Feetech SDK：

```bash
pip install -e ".[feetech]"
```

## 配置电机

**注意：**
与 SO-101 不同，SO-100 机械臂组装完成后电机连接器不易接触，因此配置步骤必须提前完成。

### 1. 查找每只机械臂对应的 USB 端口

要找到每个总线舵机适配器的端口，请运行此脚本：

```bash
lerobot-find-port
```

<hfoptions id="example">
<hfoption id="Mac">

示例输出：

```
Finding all available ports for the MotorBus.
['/dev/tty.usbmodem575E0032081', '/dev/tty.usbmodem575E0031751']
Remove the USB cable from your MotorsBus and press Enter when done.

[...Disconnect corresponding leader or follower arm and press Enter...]

The port of this MotorsBus is /dev/tty.usbmodem575E0032081
Reconnect the USB cable.
```

其中找到的端口为：`/dev/tty.usbmodem575E0032081`，对应你的 leader arm 或 follower arm。

</hfoption>
<hfoption id="Linux">

在 Linux 上，你可能需要通过运行以下命令来授予 USB 端口访问权限：

```bash
sudo chmod 666 /dev/ttyACM0
sudo chmod 666 /dev/ttyACM1
```

示例输出：

```
Finding all available ports for the MotorBus.
['/dev/ttyACM0', '/dev/ttyACM1']
Remove the usb cable from your MotorsBus and press Enter when done.

[...Disconnect corresponding leader or follower arm and press Enter...]

The port of this MotorsBus is /dev/ttyACM1
Reconnect the USB cable.
```

其中找到的端口为：`/dev/ttyACM1`，对应你的 leader arm 或 follower arm。

</hfoption>
</hfoptions>

### 2. 设置电机 ID 和波特率

在总线上，每个电机通过唯一的 ID 识别。全新电机出厂时通常带有默认 ID `1`。为了让电机和控制器之间的通信正常工作，我们首先需要为每个电机设置一个唯一、各不相同的 ID。此外，总线上数据传输的速度由波特率决定。为了彼此通信，控制器和所有电机需要配置相同的波特率。

为此，我们首先需要用控制器单独逐个连接每个电机以设置这些参数。由于我们会将这些参数写入电机内部存储器的非易失性部分（EEPROM），所以只需要执行一次。

如果你要复用其他机器人上的电机，可能也需要执行此步骤，因为 ID 和波特率很可能不匹配。

#### follower arm

将电脑的 USB 线和电源连接到 follower arm 的控制板上。然后运行以下命令，或使用上一步得到的端口运行 API 示例。你还需要使用 `id` 参数为你的 leader arm 命名。

关于如何设置电机 ID 的直观参考，请参阅[此视频](https://huggingface.co/docs/lerobot/en/so101#setup-motors-video)，其中我们演示了 SO101 机械臂的流程。

<hfoptions id="setup_motors">
<hfoption id="Command">

```bash
lerobot-setup-motors \
    --robot.type=so100_follower \
    --robot.port=/dev/tty.usbmodem585A0076841  # <- paste here the port found at previous step
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.robots.so_follower import SO100Follower, SO100FollowerConfig

config = SO100FollowerConfig(
    port="/dev/tty.usbmodem585A0076841",
    id="my_awesome_follower_arm",
)
follower = SO100Follower(config)
follower.setup_motors()
```
<!-- prettier-ignore-end -->

</hfoption>
</hfoptions>

你应该会看到以下指令：

```
Connect the controller board to the 'gripper' motor only and press enter.
```

按照指示，插上 gripper 电机。确保它是连接到板上唯一的电机，并且电机本身还没有菊花链连接到任何其他电机。当你按下 `[Enter]` 时，脚本会自动为该电机设置 ID 和波特率。

<details>
<summary> 故障排查 </summary>

如果此时出现错误，请检查线缆并确保它们正确插接：

<ul>
  <li> 电源 </li>
  <li> 电脑和控制板之间的 USB 线缆 </li>
  <li> 从控制板到电机的 3 针线缆 </li>
</ul>

如果你使用的是 Waveshare 控制板，请确保两个跳线都设置在 `B` 通道（USB）上。

</details>

你应该会看到以下消息：

```
'gripper' motor id set to 6
```

接着是下一条指令：

```
Connect the controller board to the 'wrist_roll' motor only and press enter.
```

你可以将 3 针线缆从控制板上断开，但另一端可以留在 gripper 电机上，因为它已经在正确的位置了。现在，将另一根 3 针线缆插到腕部滚转电机上，并将其连接到控制板。与上一个电机一样，确保它是板上唯一的电机，并且电机本身没有连接到任何其他电机。

按照指示，对每个电机重复上述操作。

> [!TIP]
> 在按下 Enter 之前，请检查每一步的接线。例如，在操作控制板时，电源线可能会断开。

完成后，脚本会正常结束，此时电机即可投入使用。你现在可以将每台电机的 3 针线缆依次连接到下一台电机，并将第一台电机（id=1 的'肩部偏航'电机）的线缆连接到控制板，控制板现在可以安装到机械臂的底座上。

#### leader arm

对 leader arm 执行同样的步骤。

<hfoptions id="setup_motors">
<hfoption id="Command">
```bash

    --teleop.type=so100_leader \
    --teleop.port=/dev/tty.usbmodem575E0031751  # <- paste here the port found at previous step

    id="my_awesome_leader_arm",

```

## calibration

接下来，你需要 calibrate 机器人，以确保 leader arm 和 follower arm 在相同物理位置时具有相同的位置数值。
calibration 过程非常重要，因为它让在某一台机器人上训练的神经网络也能在另一台机器人上工作。

#### follower arm

运行以下命令或 API 示例来 calibrate follower arm：

<hfoptions id="calibrate_follower">
<hfoption id="Command">

```bash
lerobot-calibrate \
    --robot.type=so100_follower \
    --robot.port=/dev/tty.usbmodem58760431551 \ # <- The port of your robot
    --robot.id=my_awesome_follower_arm # <- Give the robot a unique name
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.robots.so_follower import SO100FollowerConfig, SO100Follower

config = SO100FollowerConfig(
    port="/dev/tty.usbmodem585A0076891",
    id="my_awesome_follower_arm",
)

follower = SO100Follower(config)
follower.connect(calibrate=False)
follower.calibrate()
follower.disconnect()
```
<!-- prettier-ignore-end -->

</hfoption>
</hfoptions>

我们统一了大多数机器人的 calibration 方法。因此，这台 SO100 机械臂的 calibration 步骤与 Koch 和 SO101 的步骤相同。首先，我们需要将机器人移动到每个关节都处于其行程范围中间的位置，然后按下 `Enter`。其次，我们将所有关节在整个运动范围内移动一遍。SO101 相同过程的参考视频可在[此处](https://huggingface.co/docs/lerobot/en/so101#calibration-video)找到。
