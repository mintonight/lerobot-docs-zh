# 实时分块（RTC）

本模块包含 **实时分块（RTC）** 的 LeRobot 实现，这是一种面向基于流匹配的 policy 的 inference 时技术。

**注意**：RTC 本身不是一种 policy，而是一种 inference 增强，可与基于流匹配的 policy 配合使用，包括 [π₀](../pi0/)、[π₀.₅](../pi05/) 和 [SmolVLA](../smolvla/)。
