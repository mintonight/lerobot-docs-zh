# WALL-OSS

本仓库包含 [**WALL-OSS**](https://x2robot.com/en/research/68bc2cde8497d7f238dde690) 的 Hugging Face 移植版本。WALL-OSS 是一个基于 Qwen2.5-VL 的视觉-语言-action 模型，用于跨具身机器人控制，采用流匹配/FAST action prediction。

---

## 模型概览

| 特性            | 描述                                           |
| ------------------ | ----------------------------------------------------- |
| 基础模型         | Qwen2.5-VL（视觉-语言模型）                    |
| action prediction  | 流匹配（扩散）或 FAST（离散 token）   |
| 架构       | 带 action 特定路由的专家混合（MoE） |
| 多模态输入 | 视觉（图像/视频）、语言、本体感觉      |
