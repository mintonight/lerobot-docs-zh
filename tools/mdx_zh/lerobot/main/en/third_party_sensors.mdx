# 第三方相机与传感器

LeRobot 生态远超其原生支持的相机（OpenCV、Intel RealSense、ZMQ、Reachy 2）。得益于 LeRobot 的插件架构，社区构建了可直接替换的相机和传感器集成——从深度相机到基于视觉的触觉传感器。本页展示了社区维护的相机和传感器集成，你可以将其用于 teleoperation、数据采集和 policy deployment。

> [!IMPORTANT]
> 这些项目由第三方开发和维护。请参阅各个仓库以获取安装说明、硬件要求和支持。

可直接替换的插件会按包名自动发现：LeRobot 会导入任何以 `lerobot_camera_` 为前缀的已安装包。安装后，可直接在任何 LeRobot 命令中引用插件注册的相机 `type`（见其 README——它可能与包名不同）：

```bash
pip install lerobot_camera_<name>

lerobot-record \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.cameras="{ front: {type: <name>, width: 640, height: 480, fps: 30} }" \
    --dataset.repo_id=${HF_USER}/my-dataset \
    --dataset.num_episodes=5
```

## 贡献

构建了自己的 LeRobot 相机或传感器集成？将其打包为可安装的 `lerobot_camera_<name>` 插件，LeRobot CLI 就会自动发现它——请参阅[自带硬件](./integrate_hardware)指南和[相机](./cameras)参考以开始使用，然后与社区分享你的项目！
