# Feetech 电机固件更新

本教程将指导你使用官方 Feetech 软件更新 Feetech 电机的固件。

## 先决条件

- Windows 电脑（Feetech 软件仅适用于 Windows）
- Feetech 电机控制板
- 用于将控制板连接到电脑的 USB 线缆
- 连接到控制板的 Feetech 电机

## 第 1 步：下载 Feetech 软件

1. 访问 Feetech 官方软件下载页面：[https://www.feetechrc.com/software.html](https://www.feetechrc.com/software.html)
2. 下载最新版本的 Feetech 调试软件（FD）
3. 在 Windows 电脑上安装该软件

## 第 2 步：硬件设置

1. 将 Feetech 电机连接到电机控制板
2. 通过 USB 线缆将电机控制板连接到 Windows 电脑
3. 确保为电机供电

## 第 3 步：配置连接

1. 启动 Feetech 调试软件
2. 从端口下拉菜单中选择正确的 COM 端口
   - 如果不确定使用哪个端口，请查看 Windows 设备管理器中的“端口（COM 和 LPT）”
3. 设置适当的波特率（大多数 Feetech 电机通常为 1000000）
4. 单击“打开”以与控制板建立通信

## 第 4 步：扫描电机

1. 连接后，单击“搜索”按钮以检测所有已连接的电机
2. 软件将自动发现并列出总线上的所有电机
3. 每个电机将显示其 ID 编号

## 第 5 步：更新固件

对于每个要更新的电机：

1. 单击列表中的电机以**选择该电机**
2. **单击“升级”选项卡**：
3. **单击“在线”按钮**：
   - 如果发现可用的固件更新，它将被显示在框中
4. **单击“升级”按钮**：
   - 将显示更新进度

## 第 6 步：验证更新

1. 更新完成后，软件应自动刷新电机信息
2. 验证固件版本已更新到预期版本

## 重要注意事项

⚠️ **警告**：固件更新期间请勿断开电源或 USB，否则可能导致电机变砖。

## 附赠：在 Linux/macOS 上调试电机

仅出于调试目的，你可以使用开源的 Feetech 调试工具：

- **仓库**：[FT_SCServo_Debug_Qt](https://github.com/CarolinePascal/FT_SCServo_Debug_Qt/tree/fix/port-search-timer)

### 安装说明

按照仓库中的说明安装该工具：对于 Ubuntu 你可以直接安装，对于 MacOS 你需要从源码构建。

**局限性：**

- 该工具仅用于调试和参数调整
- 固件更新仍须在 Windows 上使用官方 Feetech 软件进行
