# 环境

simulation environment 通过 `EnvConfig` 配置，并由 `make_env` 构建。每个子类
声明其 `gym_kwargs` 以及如何构造向量化环境。

使用已发布的环境，请参见 [Hub 中的环境](../envhub)；
贡献新 benchmark，请参见[添加新 benchmark](../adding_benchmarks)。
