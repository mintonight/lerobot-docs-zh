# teleoperator

teleoperator 为机器人产生要跟随的 action——leader arm、游戏手柄、键盘、手机。它们都
实现了 `Teleoperator` 接口，因此针对该接口编写的录制脚本可与任何输入
设备配合工作。

有关设置指南，请参见[手机 teleoperation](../phone_teleop)和 [Isaac Teleop](../isaac_teleop)；有关录制工作流程，
请参见[机器人模仿学习](../il_robots)。
