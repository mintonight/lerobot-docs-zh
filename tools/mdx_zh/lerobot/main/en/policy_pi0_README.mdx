# π₀ (pi0)

本仓库包含 **π₀** 的 Hugging Face 移植版，由 Physical Intelligence 基于 [OpenPI](https://github.com/Physical-Intelligence/openpi) 适配而来。
它被设计为一个**面向通用机器人控制的视觉-语言-action 模型**。

---

## 模型概览

| 特性              | π₀                                                     | π₀.₅                                      |
| -------------------- | ------------------------------------------------------ | ----------------------------------------- |
| 时间条件    | 通过 `action_time_mlp_*` 将时间与 action 拼接 | 使用 `time_mlp_*` 进行 AdaRMS 条件化 |
| AdaRMS               | 未使用                                               | 用于 action expert                     |
| 分词器长度     | 48 个 token                                              | 200 个 token                                |
| 离散 state 输入 | False（使用 `state_proj` 层）                        | True                                      |
| 参数量      | 更高（包含 state 嵌入）                      | 更低（无 state 嵌入）                |

---

## relative action

π₀ 支持使用**relative action**进行训练，即模型学习相对于当前机器人 state 的相对偏移，而非绝对关节位置。这与 OpenPI 中的 relative action 变换（`DeltaActions`）一致，可以提升性能。

### 工作原理

1. **在预处理期间**，absolute action 被转换为相对偏移：
   `relative = action - state`（针对选定的关节）。
2. 使用从相对分布计算得到的统计量对 relative action 进行归一化。
3. **在后处理期间**，预测的 relative action 被转换回 absolute action：
   `absolute = relative + state`。

列在 `relative_exclude_joints` 中的关节（例如 gripper）保持绝对。

### 配置

| 参数                 | 类型        | 默认值       | 描述                                                      |
| ------------------------- | ----------- | ------------- | ---------------------------------------------------------------- |
| `use_relative_actions`    | `bool`      | `False`       | 启用 relative action 训练                                  |
| `relative_exclude_joints` | `list[str]` | `["gripper"]` | 保持绝对的关节名称（按子串匹配）              |
| `action_feature_names`    | `list[str]` | `None`        | 运行时由 `make_policy` 自动从 dataset 元数据填充 |

### 训练示例

```bash
python -m lerobot.scripts.lerobot_train \
  --policy.type=pi0 \
  --dataset.repo_id=your_org/your_dataset \
  --policy.use_relative_actions=true \
  --policy.relative_exclude_joints='["gripper"]'
```

当 `use_relative_actions=true` 时，训练脚本会自动：

- 从 dataset 计算 relative action 统计量（采样的 action chunk 级 relative action）
- 用相对统计量替换标准 action 统计量以进行归一化
- 在分布式训练中将这些统计量广播到所有 rank

### 为现有 dataset 重新计算统计量

如果你想离线预计算 relative action 统计量，请使用来自
`lerobot.datasets` 的 `recompute_stats`：

```python
from lerobot.datasets import LeRobotDataset, recompute_stats

dataset = LeRobotDataset("your_org/your_dataset")
dataset = recompute_stats(
    dataset,
    relative_action=True,
    relative_exclude_joints=["gripper"],
)
```
