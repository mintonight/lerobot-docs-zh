# VLA-JEPA

本仓库包含 **VLA-JEPA** 的 LeRobot 移植版，这是一个视觉-语言-action 模型，将 Qwen3-VL 语言骨干网络与自监督视频世界模型（V-JEPA2）以及流匹配 DiT action 头相结合。

从 [ginwind/VLA-JEPA](https://huggingface.co/ginwind/VLA-JEPA) 转换而来。

---

## 架构概览

| 组件                    | 模块                              | 作用                                                    |
| ----------------------- | --------------------------------- | ------------------------------------------------------- |
| **Qwen3-VL 骨干**       | `Qwen3VLInterface`                | 将图像与语言指令融合为上下文 token |
| **DiT-B action 头**        | `VLAJEPAActionHead`               | 在 action chunk 上进行流匹配扩散           |
| **V-JEPA2 世界模型**    | `ActionConditionedVideoPredictor` | 自监督视频预测损失（仅训练时）   |

inference 时只使用 Qwen 骨干和 action 头；不需要世界模型。
